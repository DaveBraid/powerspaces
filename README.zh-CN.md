# PowerSpaces 中文说明

[English](README.md) · [构建、安装与完整中文使用说明](docs/zh-CN.md)

本 fork 保留上游的原生多桌面管理，让聚焦和新建窗口尽量在当前桌面完成；支持 English / 简体中文，以 macOS 27 为主要适配环境。

## 程序坞外观

- 使用原生 Liquid Glass，可分别设置明暗、着色强度和玻璃透光率。
- “跟随系统”且未着色时，没有颜色可供“着色强度”调节，因此禁用该滑块；选择浅色、深色或启用着色即可调节。透光率独立生效。
- 透光率越高，背景模糊和底色越弱；0% 恢复系统的背景模糊和底色。原生边缘高光保持不变，图标不随背景淡出。百分比表示调节程度，不是物理透射率。
- 窗口标题默认按其下方实际背景明暗自动调整黑白颜色；“设置 → 窗口”可关闭自动适配并使用自定颜色。
- 设置窗口的玻璃效果跟随系统，不提供独立透明度选项。

## 兼容说明

透光率、原生高光和背景感知标题使用隔离的 **macOS 27 私有渲染接口**。仅在系统版本和接口探测通过时启用；未知系统回退原生玻璃及语义文字颜色，系统“降低透明度”优先。系统更新后可能需要适配。

这些功能不截图、不通过定时器采样屏幕，也不修改系统全局 Liquid Glass 设置。

开发中只维护重要经验，见[开发经验](docs/development-experience.md)。构建与后续自动应用约定见[中文指南](docs/zh-CN.md)。


**原生 Dock 配方**：已验证的 Apple Silicon macOS 27.0（`26A428`）使用 DesignLibrary 的 `.dock` 背景材质，通过仅影响渲染的 `windowAppearsActive` 环境保留独立高光。PS 在后台和窗口非焦点时仍保持高光，不激活应用或抢焦点。删除自定义高光层及滑块，保留配方原生光效，透光率继续只调背景模糊和底色。符号缺失、类型布局变化、未验证的系统构建或渲染检查失败时回退 `NSGlassEffectView`；设置窗口继续使用公开原生玻璃。复用材质不意味着复刻系统 Dock 的所有私有动效和参数。

### 程序坞分区与缩放

运行中的程序显示小圆点；未运行的固定程序继续变灰。全局固定和当前桌面固定合并在前区，分割线后显示当前桌面未固定的运行程序。保存的顺序与拖动排序在各自分区内生效，应用启动器放在固定区。

无窗口应用在 PS 会话内保留最后观察到的桌面和显示器归属；首次遇到无窗口应用时归入活动桌面。macOS 不提供无窗口进程的 Space 归属，重启 PS 后需重新推定。仅在其他桌面有窗口的应用不会混入当前桌面的运行区。固定项的小圆点反映全局运行状态。

悬停时邻近图标连续放大并互相让位，现有缩放设置控制最大倍率，默认 1.5×，保留已有自定义值；“减少动态效果”会禁用缩放。标题单独分配图文区域，短标题按实际长度收缩，设置中的标题宽度作为最大值；超长窗口标题仍可通过悬停提示查看全文。

“图标”页可调整运行圆点间距（0–20 点，默认 5 点）。缩放时圆点靠屏幕边缘一侧的坐标固定，另一轴跟随图标中心。固定项分割线整体自适应纯黑／纯白，始终对齐玻璃横截面中心，可关闭；长度可调（基础图标尺寸的 20–100%，默认 65%）；每侧额外留白可独立于图标间距调节（0–24 点，默认 8 点）。

“设置 → 图标 → 分割线粗细”可调 0.5–4 点，默认 1 点；与长度和两侧间距独立。

开启设置中的“高级”后显示玻璃透光率、着色强度及分割线粗细、长度、两侧留白；关闭“高级”仅隐藏控件，保留已保存的效果。
