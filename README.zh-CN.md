# PowerSpaces 中文说明

[English](README.md) · [构建、安装与完整中文使用说明](docs/zh-CN.md)

本 fork 保留上游的原生多桌面管理，让聚焦和新建窗口尽量在当前桌面完成；支持 English / 简体中文，以 macOS 27 为主要适配环境。

## 程序坞外观

- 使用原生 Liquid Glass，可分别设置明暗、着色强度和玻璃透光率。
- “跟随系统”且未着色时，没有颜色可供“着色强度”调节，因此禁用该滑块；选择浅色、深色或启用着色即可调节。透光率独立生效。
- 透光率越高，背景模糊和底色越弱；0% 恢复系统的背景模糊和底色。原生边缘高光增强独立保留，图标不随背景淡出。百分比表示调节程度，不是物理透射率。
- 窗口标题默认按其下方实际背景明暗自动调整黑白颜色；“设置 → 窗口”可关闭自动适配并使用自定颜色。
- 设置窗口的玻璃效果跟随系统，不提供独立透明度选项。

## 兼容说明

透光率、边缘高光增强和背景感知标题使用隔离的 **macOS 27 私有渲染接口**。仅在系统版本和接口探测通过时启用；未知系统回退原生玻璃及语义文字颜色，系统“降低透明度”优先。系统更新后可能需要适配。

这些功能不截图、不通过定时器采样屏幕，也不修改系统全局 Liquid Glass 设置。

开发中只维护重要经验，见[开发经验](docs/development-experience.md)。构建与后续自动应用约定见[中文指南](docs/zh-CN.md)。

在“设置 → 程序坞 → 布局”实时调节两侧边缘高光：强度 0–200%（0 关闭），宽度 0.25–3×；默认 100%／1×，保留此前效果，与透光率独立。

**高光已知限制**：当前滑块调节背景滤镜；AppKit 在窗口失活时会关闭独立前景高光，因此现有滑块还不能在 PS 的非激活面板中复现原生 Dock 上下高光。激活状态根因已通过对照复现，渲染修复尚未完成。
